## Architecture Decisions

- `ghost-ai-components` was generated with `nx g @nx/react:library --bundler=none --unitTestRunner=none --component=false --importPath=@org/ghost-ai-components --useProjectJson=true`, matching the non-buildable, test-less setup of the existing `shadcn`/`shadcn-util` libs. Unlike those two, the generator produced a `package.json` for it (current `@nx/react` default); kept it since the root `package.json` already declares npm workspaces (`apps/*`, `libs/*`, `api`), so it resolves correctly via the workspace symlink in `node_modules/@org` without needing a manual `tsconfig.base.json` path entry.

## Session Notes

- After generating a new lib (or otherwise changing project dependency edges — including a project's *first* import of an existing lib, e.g. wiring `ghost-ai-components` into `apps/ghost-ai`), run `npx nx reset` before relying on `nx run-many`/Tailwind's `createGlobPatternsForDependencies` — the cached project graph the dev server's Tailwind config reads (`readCachedProjectGraph()`) does not pick up the new/changed dependency edge otherwise, so the lib's classes silently don't make it into the Tailwind content scan even after restarting `next dev` and clearing `.next`. `nx reset` alone isn't enough — it clears the cache but doesn't repopulate it (`createGlobPatternsForDependencies` then errors with "No cached ProjectGraph is available" and silently returns `[]`); follow it with any command that recomputes the graph (e.g. `npx nx show projects`) before starting the dev server. Confirmed twice now; not a Turbopack bug, just a stale-graph gotcha. Also run `npx nx sync` after the new import so TS project references stay accurate (it had been silently warning "workspace out of sync" since the import predated the reference).
- The workspace-wide `shadcn-util:build` / `shadcn:build` nx targets currently fail (`error TS5072: Unknown build option '--useLegacyTypescriptPlugin=true'`) due to `nx.json`'s `targetDefaults.build.options.useLegacyTypescriptPlugin: true` being incompatible with the installed TypeScript version.
